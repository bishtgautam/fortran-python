# Cython Approach

Fortran calls compiled Cython extension modules.

## Architecture
```
Fortran (ISO_C_BINDING) → Cython-generated C code → Python (optional)
```

## Features
- ✅ Compiled to native code for performance
- ✅ Automatic type conversion
- ✅ Less boilerplate than C API
- ⚠️ Python code must be Cython-compatible
- ⚠️ Requires Cython build step
